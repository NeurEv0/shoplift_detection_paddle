## 1. 完整管线架构（每帧）

```
stream frame
  ├─ PP-Human MOT        行人检测 + 跟踪              → person_tracks
  ├─ keypoint            姿态 + 手部 ROI               → body_poses / hand_regions
  ├─ person_attribute    手持状态 (holding_product)    → proxy_item_regions
  ├─ item_container      9 类容器检测                  → items / containers
  ├─ 事件引擎 ShopliftingEventEngine
  │    ├─ near_body_suspicious          （持商品贴近身体）
  │    ├─ bag_concealment               （商品进私有容器 bag/backpack）
  │    └─ private_container_concealment （私有容器进公有容器，两段式 nested_concealment）
  ├─ PP-TSM open         人像 16 帧滑窗 @3.125fps      → open 概率 → 事件化（连续≥3窗≥0.6）
  └─ FusionEngine        商品判定门 + 拆包段合并        → package_opening 事件（high 0.80）
```

关键设计点：
- 检测/跟踪/属性/容器均为**静态图 predictor**（`paddle.inference.create_predictor`），共享权重；
- PP-TSM open 为**动态图**（`paddle.nn.Layer`），与静态图**不能同进程共存**——离线批跑两阶段子进程隔离，实时单进程内用独立 dygraph 模型加载；
- 容器模型是 9 类闭集（bag/backpack/handbag/suitcase/basket/cart/plastic_bag/stroller/helmet），**没有"商品"类**；"item"（商品）信号来自人员属性模块的 `holding_product` 手部代理区域（proxy_item）。

融合配置关键参数（`fusion.example.yml`）：
- 事件化：`theta=0.6`，`min_consecutive_windows=3`（连续 ≥3 窗概率 ≥0.6 = 一次拆包）
- 商品判定门：`min_product_confirm_frames=14`（拆包窗口内连续 ≥14 帧 holding_product 才算"拆的是商品"），`min_holding_product_score=0.5`
- 拆包段合并：`merge_temporal_gap_ms=5000`，`merge_iou_threshold=0.3`
- 独立事件：`standalone_event_type=package_opening`，`standalone_risk_score=0.80`
- 时间线重采样：`timeline_fps=3.125`（25fps ÷ 8，与训练 master 节奏一致）

## 4. 两个视频的测试效果

### 4.1 cc015（yulong_store 超市，装包型偷盗，92s / 2300 帧，1280×720）

检测管线事件（`pipeline.cc015_v7b_classw102_test.yml` + nested_concealment v13）：

| 指标 | 数值 |
|---|---|
| 总事件 | **67** = 64 near_body_suspicious + 2 bag_concealment + **1 private_container_concealment** |
| 真事件 | **person-71 `private_container_concealment` HIGH 0.78 @33.36s**（"私有容器进公有容器"两段式规则检出）|
| 容器检测 | 贴篮背包幻影 -86%（12888→1798），真包检出 0.55→0.83（更聚焦）|

PP-TSM open：**0 拆包装事件**（cc015 的偷盗是"装包"型——把私有背包放进店内篮，无撕包装动作，由 private_container_concealment 规则承载，不靠 PP-TSM）。

已知短板：
- **person-71 黑挎包无 bag_concealment 事件（最老问题，与模型无关）**：MOT 在 f552-585+ 存在跟踪空洞（人物贴右缘 x2=1280 被裁），item 轨与容器关联断裂，事件引擎看不到完整"入包"链。修法在 MOT 稳定性/贴边处理。

### 4.2 D03（堂食区，开袋型偷盗 + 手机负样本，22591 帧，2560×1440）

检测管线事件（`pipeline.d03_v7b_m80_classw102_test.yml` + nested_concealment v13）：

| 指标 | 数值 |
|---|---|
| 总事件 | **57** = 53 near_body_suspicious + 4 bag_concealment |
| 真事件 | **person-472 concealment HIGH 0.85 @576480-576920ms**（标注真偷，保住）|
| 手机负样本 | person-316 持手机误报已修复（v7 训练数据加 8 帧手机负样本）|
| 回归 | 与 classw102 基线**字节级一致**（0 新增误报）|

PP-TSM open（v2 ep26，在 9 条 master 时间线上）：
- **steal_2（开袋→购物车）与 steal_3（开袋→自己包，未见视频）均触发拆包事件**；
- **7 条非拆包时间线（含吃面/装袋/静止）零误报**（事件规则 θ=0.6、连续≥3 窗）。

遗留误报（HIGH，待规则层修，非模型）：
- person-69 / 76 / 422：疑似"正常把商品放进自备购物篮/车/袋"被语义化为 concealment（`basket/cart 判 normal` 的语义规则尚未落地）。

> D03 视频为损坏参考帧的 HEVC 封装，**必须顺序解码**（随机 seek 会产出灰白坏帧）。

## 6. 运行命令

### 6.1 离线批跑（单视频，检测管线 + 事件引擎）

```bash
SHOPLIFT_USER=wqh <env-python> -m shoplift.cli.video_infer_visualize \
  --config shoplift/configs/pipeline.cc015_v7b_classw102_test.yml \
  --input datasets/test/test_videos/yulong_store/cc015bb3e050a8bc67ebbb2e6fd9951d.mp4 \
  --output outputs/wqh/container_pa_test/cc015_v7b_classw102_v13test
```

> `--input` 默认值会覆盖 yml，必须显式传视频路径。

### 6.2 实时推理（含 PP-TSM open + 融合）

```bash
python -m shoplift.cli.realtime_infer \
  --pipeline-config shoplift/configs/pipeline.cc015_v7b_classw102_test.yml \
  --camera-id realtime-cam-001 \
  --source /dev/video0 \
  --open-config shoplift/configs/paddlevideo/pptsm_open_v2_fight16.yaml \
  --open-weights outputs/wqh/paddlevideo/pptsm_open_v2_fight16/ppTSM_epoch_00026.pdparams \
  --paddlevideo-root third_party/PaddleVideo \
  --fusion-config shoplift/configs/fusion.example.yml \
  --output-dir outputs/realtime/single_stream \
  --per-model --duration 300 --summary-every 2
```

### 6.3 多流并行

```bash
python -m shoplift.cli.multi_stream_parallel \
  --pipeline-config shoplift/configs/pipeline.cc015_v7b_classw102_test.yml \
  --sources <源1,源2,...> --camera-id <id> \
  --open-config shoplift/configs/paddlevideo/pptsm_open_v2_fight16.yaml \
  --open-weights outputs/wqh/paddlevideo/pptsm_open_v2_fight16/ppTSM_epoch_00026.pdparams \
  --paddlevideo-root third_party/PaddleVideo \
  --fusion-config shoplift/configs/fusion.example.yml
```
